# Decisions

- 2026-10-17: Committed `signals_cached.csv` is the SPEC 5.1 synthetic duck curve. Reason: no documented provider returned 48 hourly GridSignal rows (EIA timeout, CAISO timeout, Electricity Maps latest is one hour, WattTime credentials absent, no WRI URL in `/docs/data_sources.txt`). Alternative rejected: replace the cache with a partial live series.
- 2026-10-17: Solve the full schedule with one `scipy.optimize.milp` call (HiGHS, time_limit 1.5, mip_rel_gap 1e-4). Reason: SPEC section 7. Alternative rejected: a separate LP for checkpointable jobs, or PuLP.
- 2026-10-17: Water is only the alpha-weighted objective term. Reason: section 7 says alpha only changes the three coefficients. Alternative rejected: a hard cap of (1 - alpha) times baseline water from the section 1 overview.
- 2026-10-17: `created_at` and the optimized schedule id come from `optimizer.clock.now_utc`. Fractions and metrics do not. Reason: the SPEC id includes a timestamp, and tests need one clock to patch. Alternative rejected: stamp every schedule with horizon_start. The `-b`/`-c` id suffix for same-second collisions stays in the backend store.
- 2026-10-17: SQLite is the default backend store; Postgres/Timescale per SPEC section 8 is implemented but untested live. Reason: `DATABASE_URL` empty and `/docs/tigerdata.txt` missing (credentials gate). Alternative rejected: block the backend on Tiger Cloud credentials.
- 2026-10-17: `psycopg[binary]==3.2.13` added for the Postgres path. Reason: SPEC's stack has no Postgres driver; psycopg 3 is the current standard driver and is only imported when DATABASE_URL starts with postgres. Alternative rejected: SQLAlchemy (heavier, not in the pinned stack).
- 2026-10-17: `record_settlement` runs synchronously inside `approve_and_apply` after the applied commit. Reason: mock returns instantly and a shared DB connection across threads is more fragile; SOL-3 still holds on failure. Alternative rejected: a detached thread task.
- 2026-10-17: The HORIZON_MODE=today rebase offset snaps to whole hours. Reason: zones with non-hour-aligned UTC offsets (e.g. +5:45) would otherwise produce non-hour-aligned slot timestamps and fail GridSignal validation at startup. Alternative rejected: crash on such zones.
- 2026-10-17: `photon_router` answers both POST /api/webhooks and POST /api/webhooks/photon. Reason: SPEC says the router is mounted at /api/webhooks and routes POST "", which would make the path /api/webhooks, but the public path everywhere else is /api/webhooks/photon.
- 2026-10-17: Frontend pinned to React 18.3.1 over the Vite 8 scaffold's React 19. Reason: the task spec requires React 18 and Recharts/Testing Library peer support is proven there. Alternative rejected: adopt React 19.
- 2026-10-17: Tailwind v4 (`@tailwindcss/vite`) over v3. Reason: v3's transitive deps (chokidar->braces, postcss-nested->postcss-selector-parser) carry unpatched advisories; v4 needs no PostCSS config and audits clean. Alternative rejected: ship v3 with dev-only advisories.
- 2026-10-17: `React.StrictMode` removed in `main.tsx`. Reason: dev double-mount fires duplicate optimize calls and SSE connections, polluting the demo decision log. Alternative rejected: keep StrictMode with init guards.
- 2026-10-17: The offline fallback is a full mock `ApiClient` (state machine + fixtures) selected when health fails or `VITE_API_URL` is unset. Reason: SPEC 15 requires the page to render fixtures on health failure; one interface keeps all panels identical across modes. Alternative rejected: per-panel fixture branches.
- 2026-10-17: `?alpha=` query param sets the first optimize alpha. Reason: needed deterministic alpha 0/1 states for the required screenshots; also a useful demo deep-link. Alternative rejected: driving the slider in the screenshot tool only.
- 2026-10-17: Recharts `isAnimationActive={false}` on all series. Reason: mount animation replays on every poll/update and screenshot timing caught half-drawn lines. Alternative rejected: longer screenshot waits.
- 2026-10-17: Gemini live call is a single seam `_generate_model_text` that raises until `/docs/gemini.txt` documents the SDK. Reason: no documented request shape exists and SPEC forbids guessing; the 6 s bound is enforced by a worker-thread future so it holds whatever call lands there. Alternative rejected: call the google-genai SDK from memory.
- 2026-10-17: `shifted_jobs.from_hours` compares against `prev_schedule` (falling back to `sch-baseline` when null). Reason: section 11 passes the previously applied schedule, which is the baseline in the demo flow and matches section 5.4's shifted definition. Alternative rejected: always load sch-baseline, which would mislabel moves relative to an already-applied optimized schedule.
- 2026-10-17: Gemini error log messages contain only fixed strings and `type(exc).__name__`, never `str(exc)`. Reason: SDK errors can embed `?key=` URLs and would leak GEMINI_API_KEY into the decision feed. Alternative rejected: log and then mask.
- 2026-10-17: Negotiation is FETCHAI_MODE=local only; `network` logs an `agents` error and falls back to local. Reason: `/docs/fetchai.txt` is missing and SPEC 12 forbids inventing SDK calls. Alternative rejected: block `negotiate()` on Fetch.ai docs/credentials.
- 2026-10-17: ev-agent emits one `counter` per violating ev_charge job (job_id ascending). Reason: the merge rule keys `job_deadlines` by job and both sample EV jobs can violate at once. Alternative rejected: one counter naming only the lowest job_id, leaving the other job unconstrained.
- 2026-10-17: A malformed or crashed agent reply is executed as neither accept nor counter: error-logged (`integration` `agents`), and the flow still merges remaining counters and re-optimizes. Reason: "not executed" (SPEC 12) should not silently accept a possible violation. Alternative rejected: treat the dropped reply as accept.
- 2026-10-17: The 8 s wall clock is one worker thread + `future.result(timeout=8)`; a timed-out worker may finish in the background (the only blocking call, `optimize`, self-limits at 1.5 s). Reason: `negotiate()` is sync code invoked via `asyncio.to_thread`; signal-based timeouts are Unix-only. Alternative rejected: async refactor of the optimize signature.
- 2026-10-17: grid-agent's `inform` reads `state.signals`, not the boosted copy used inside `/api/demo/trigger-surplus`. Reason: the modified signals are never stored; `state.signals` is the only horizon the bridge can see. Alternative rejected: stash throwaway signals in app state (D1-owned).
- 2026-10-18: `uagents==0.26.1` added to requirements for `FETCHAI_MODE=network`. Reason: the lead pointed at the web/installed package for Fetch.ai docs, and the invariants allow calls verified in the installed package source. Supersedes the local-only line above, which applied while no docs existed. Alternative rejected: continue forbidding network mode.
- 2026-10-18: Network transport runs all four agents in one in-process `Bureau` on loopback, with `RulesBasedResolver` mapping each seed-derived `agent1q` address to the bureau `/submit` endpoint. Reason: real HTTP envelope delivery with zero Almanac/Agentverse dependency, so it works offline and in tests. Alternative rejected: Agentverse-hosted agents (needs live accounts, brittle for the demo).
- 2026-10-18: `FETCHAI_API_KEY` / `ASI_ONE_API_KEY` are not read by network mode. Reason: the local bureau authenticates nothing; the keys only matter for hosted features (mailbox, Search API, Almanac writes) that section 12 does not require. Alternative rejected: gate `FETCHAI_MODE=network` on the keys being present.
- 2026-10-18: The bridge pre-warms the shared uAgents bureau at import (app startup) when `FETCHAI_MODE=network`, and `NegotiationNetwork` installs an event loop on whichever thread builds it. Reason: `Agent` construction needs a loop and both the warm-up thread and the real `asyncio.to_thread(negotiate)` path run on loop-less threads — without this, network mode silently fell back to local; also moves the ~2 s bureau boot out of the 8 s negotiation clock. Alternative rejected: accept the cold-start cost on the first call.
- 2026-10-18: `solders==0.29.0` for the Solana memo transaction, sent via plain JSON-RPC over the already-installed `httpx`. Reason: SPEC 14 requires calls from the installed solders or solana package; solders is the small Rust binding the heavier solana-py wraps, and two RPC methods (getLatestBlockhash, sendTransaction) need no client library. Alternative rejected: solana-py + spl-token (much larger dep tree for one memo instruction).
- 2026-10-18: The live send runs on a daemon thread inside `record_settlement`, which returns None immediately and lets the thread write the settlement_tx or error row. Reason: SPEC 14 wants the send as a background task that never blocks the applied schedule, but `schedules.approve_and_apply` (out of this task's edit scope) calls it synchronously — backgrounding inside the function satisfies the contract from within the owned file. Alternative rejected: blocking send (up to 10 s) in the approve path.
- 2026-10-18: Caddy (not nginx) terminates the public edge in deploy/. Reason: automatic Let's Encrypt issuance/renewal with one env var (SITE_ADDRESS) satisfies "HTTPS when a domain is set, HTTP on the IP otherwise" without certbot plumbing. Alternative rejected: nginx + certbot (two extra moving parts).
- 2026-10-18: Ubuntu `docker.io` + `docker-compose-v2` apt packages in provision.sh. Reason: boring distro packages, no external Docker apt repo to key or pin. Alternative rejected: Docker CE convenience script (pulls an external repo).
- 2026-10-18: One server env file (`deploy/.env`) doubles as compose interpolation and backend env_file. Reason: one place to type values on the server; infra keys (SITE_ADDRESS, PUBLIC_URL) are ignored by the app. Alternative rejected: split infra.env + app.env (two files to drift).
- 2026-10-18: Horizon rebase and `now_dt()` both go through `backend.clock.now_utc`. Reason: SPEC section 4 says the backend reads the clock in one function so a test can move local midnight. Alternative rejected: `datetime.now` inside `signals.py`.
- 2026-10-18: The dashboard re-reads a `pending_approval` schedule every 2 seconds. Reason: a Photon YES applies the row on the server, and the status chip was staying pending with Approve still enabled. Alternative rejected: a second SSE client in the page.
- 2026-10-18: Water is a hard budget row, `water_l <= (1 - alpha) * water_base`, and the objective is `0.3 cost + 1.0 carbon`. Reason: the project brief's part 4 table and its "21 distinct results" rule; the weighted form had a cliff at alpha 0.10. Supersedes the 2026-10-17 weighted-term line. Alternative rejected: keep the weighted term and add a tie-break.
- 2026-10-18: A `settlement_tx` row links out only when `payload.explorer_url` is a string. Reason: SPEC 15, and mock signatures are not devnet transactions. Alternative rejected: building `explorer.solana.com/tx/mocksig-...`.
- 2026-10-18: Gemini live uses REST generateContent with x-goog-api-key header and no thinkingConfig; recommended GEMINI_MODEL=gemini-flash-lite-latest (2 s, fits the 6 s bound). Reason: thinkingConfig 400s on non-thinking models and gemini-flash-latest spends ~1100 thought tokens (8 s) by default. Alternative rejected: a GEMINI_THINKING_BUDGET env var (new SPEC var for one model family).
